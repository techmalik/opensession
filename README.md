# OpenSession

Open-source speaker and content management for conferences. Built for the Kill My
SaaS competition as a replacement for Sessionboard: call for papers, abstract review,
speaker portal, content collection, agenda building, and public schedule embeds.

Status: scaffold + data model + seed. Feature phases tracked in `prompts/`.

## Stack

React Router v7 (SSR) on Cloudflare Workers, D1 (Drizzle ORM), optional R2,
Tailwind CSS. Email via Brevo behind an abstraction with a full in-app send log.
Two-way Airtable sync (D1 is the runtime store, Airtable is the team-editable
mirror). Jobs run through a D1 outbox table on a 5-minute cron.

## Local development

```bash
npm install
cp .dev.vars.example .dev.vars   # set SESSION_SECRET at minimum
npm run db:local                 # apply migrations + seed to local D1
npm run dev
```

## Deploy

```bash
npx wrangler login
npx wrangler d1 create opensession-db     # paste database_id into wrangler.jsonc
npx wrangler secret put SESSION_SECRET
npm run db:remote
npm run deploy
```

Optional secrets: BREVO_API_KEY (real email delivery), AIRTABLE_API_KEY +
AIRTABLE_BASE_ID (two-way sync), ANTHROPIC_API_KEY (AI features fallback when
Workers AI is unavailable).

## Repository map

- `CLAUDE.md` build rules; `DESIGN.md` enforced design system
- `database/schema.ts` full data model; `database/seed.sql` generated by `npm run seed:gen`
- `spec/` vendored eval-kit docs, specs, and fixtures (the scoring rubric)
- `prompts/` phase-by-phase build prompts
- `app/lib/` auth, email, storage, jobs primitives
